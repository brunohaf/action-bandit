# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.3   | :white_check_mark: |
| < 1.4.3 | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/brunohaf/action-bandit/security/advisories/new) for this repository, do not open a public issue.

You can expect an initial response within 5 business days. If the vulnerability is accepted, we'll work with you on a fix and coordinate a disclosure timeline before publishing an advisory. If declined, we'll explain why.
